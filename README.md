# Answerwa Tap

## How do I install these formulae?

`brew install answerwa/tap/<formula>`

Or `brew tap answerwa/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "answerwa/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
